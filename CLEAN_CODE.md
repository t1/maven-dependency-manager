# Clean Code Principles

This project follows Clean Code principles provided by the **tdder** plugin.

Install the plugin from: `/Users/rdohna/workspace/tools/claude-plugins/tdder`

The plugin provides:
- Clean Code principles (naming, SOLID, code smells, method design, refactoring patterns)
- Clean Code Reviewer agent for automated code review
- Refactoring checklist

See the plugin's `skills/clean-code/SKILL.md` for the full Clean Code principles.
