# Test-Driven Development (TDD) Rules

This project follows strict TDD practices provided by the **tdder** plugin.

Install the plugin from: `/Users/rdohna/workspace/tools/claude-plugins/tdder`

The plugin provides:
- Core TDD process (Red-Green-Refactor, baby steps, guessing game)
- Clean Code review during refactor phases (via subagent)
- APP (Absolute Priority Premise) mass calculations
- Human-in-the-loop configuration

See the plugin's `skills/tdd/SKILL.md` for the full TDD process.
